# Изменения за 13-08-2026

## Исправление квитирования и обработки кратковременной потери датчиков

- Исправлено повторное появление аварийного окна после квитирования при сохраняющейся причине аварии.
- После ACK текущий alarm episode не возвращается в `pending/unacked` в каждом цикле.
- Для `dT` ACK-путь приведён к той же модели текущего episode без повторного re-latch.
- Исправлена обработка кратковременной потери датчиков температуры и давления.
- Восстановление датчика до истечения timeout теперь отменяет pending sensor-loss и не формирует пользовательскую тревогу.
- Для уровня уточнён текст события: `Уровень MAX`.
- Для `T1/T2/T3/P` задержки пользовательских тревог и управления открыты в интерфейсе.
- Raw fault и существующая fail-safe реакция управления сохранены.
- Правка выполнена в общем коде для `FULL` и `LIGHT`.

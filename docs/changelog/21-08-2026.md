# Изменения 21-08-2026

## Исправление ложных событий удалённых сенсоров в LIGHT

- Добавлен явный compile-time выбор профиля: FULL использует `PROFILE_FULL`, LIGHT — `PROFILE_ECONOMY_LIGHT`.
- Профиль публикуется в startup diagnostics и read-only API (`/api/v1/info`, `/api/v1/version`).
- Удалённые сенсоры `T3`, `P`, `L`, `F`, `C` и `V` исключены из LIGHT runtime и event-log transition path.
- Записи `Потеря датчика T3` и `Потеря датчика давления` не формируются в корректной LIGHT-прошивке.
- Поведение FULL, включая sensor-loss для `T3`/`P`, сохранено.
- LIGHT-сборка должна быть проверена по `ACTIVE_PROFILE`, а не только по названию команды или каталога сборки.

Версия: `1.7.14` → `1.7.15`.

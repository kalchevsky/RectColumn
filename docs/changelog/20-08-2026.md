# Изменения 20-08-2026

## Независимая LED-индикация в профиле LIGHT

- В едином приложении добавлена профильная LED-индикация для `LIGHT`.
- Состояние реле `CH1` отображается отдельным LED через экспериментальный GPIO18.
- Аварийная LED-индикация работает независимо через экспериментальный GPIO32.
- `CH5`/GPIO13 сохранён как buzzer; GPIO14 сохранён как ACK.
- В `LIGHT` CH4/GPIO32 больше не используется как звуковой bell-channel.
- Добавлены настройки `relayLedIndicatorEnabled` и `alarmLedIndicatorEnabled`, API и переключатели UI.
- LED реле и аварийный LED отключаются независимо от реле и buzzer.
- Поведение `FULL` сохранено без изменений.
- GPIO18 и GPIO32 требуют последующего подтверждения электрической схемой платы LIGHT.

### Проверки

- `arduino-cli compile ... --build-path .build-light .` — успешно.
- `arduino-cli compile ... --build-path .build-full .` — успешно.
- `python WEB_SRC/generate_embedded_web.py all --check` — успешно.
- `git diff --check` и host/unit-тесты — выполнить перед публикацией.

### Версия

- Старая версия: `1.7.13`
- Новая версия: `1.7.14`

## Исправление ложных событий удалённых сенсоров в LIGHT

- Добавлен явный compile-time выбор профиля: FULL использует `PROFILE_FULL`, LIGHT — `PROFILE_ECONOMY_LIGHT`.
- Фактический профиль публикуется в startup diagnostics и read-only API (`/api/v1/info`, `/api/v1/version`).
- Удалённые сенсоры `T3`, `P`, `L`, `F`, `C` и `V` исключены из LIGHT runtime и event-log transition path.
- Поведение FULL, включая sensor-loss для `T3`/`P`, сохранено.
- LIGHT-сборка должна быть проверена по `ACTIVE_PROFILE`, а не только по названию команды или каталога сборки.

Версия: `1.7.14` → `1.7.15`.

## Корректное журналирование повторной потери T2

- EventLog теперь отслеживает переход опубликованного sensor-loss состояния, а не sticky-флага до операторского ACK.
- Потеря активного T2 записывается один раз на каждый эпизод fault; после восстановления и повторной потери появляется новая отдельная запись.
- Фильтр профиля LIGHT и поддержка sensor-loss для T3/P в FULL сохранены.
